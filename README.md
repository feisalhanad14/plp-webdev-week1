# My First Page

A personal portfolio webpage built using semantic HTML5 elements and hosted on GitHub Pages.

**Live Site:** https://your-github-username.github.io/plp-webdev-week1/

## Reflection
Using semantic HTML elements like `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>` instead of generic `<div>` tags gives the webpage clear structure and meaning. This makes the code easier to read for developers and significantly improves accessibility for screen readers and search engines.
